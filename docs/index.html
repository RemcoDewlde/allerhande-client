Quick start

Search recipes

import { AllerhandeClient } from "allerhande-client";

const client = new AllerhandeClient();

const { page, result } = await client.searchRecipes("pasta carbonara");

console.log(page.total);              // e.g. 42
console.log(result[0].title);         // "Pasta carbonara"
console.log(result[0].slug);          // "pasta-carbonara"
console.log(result[0].tags);          // [{ key: "keuken", value: "italiaans" }, ...]
console.log(result[0].nutrition?.energy); // { value: 275, unit: "kcal" }

Fetch a full recipe

const recipe = await client.getRecipe(1202199);

console.log(recipe.description);
console.log(recipe.cookTime);             // minutes as number
console.log(recipe.preparation.steps);   // string[]
console.log(recipe.ingredients);         // [{ id, quantity }, ...]
console.log(recipe.tips);                // [{ type, value }, ...]

Page through all results

for await (const recipe of client.searchAll("soep")) {
  console.log(recipe.title);
  // Automatically fetches next pages until exhausted
}

Examples

Sort and filter

// Most popular Italian main courses
const { result } = await client.searchRecipes("pasta", {
  size: 20,
  sortBy: "POPULAR",
  filters: [
    { group: "menugang", values: ["hoofdgerecht"] },
    { group: "keuken",   values: ["italiaans"]    },
  ],
});

Filter by ingredient

const { result } = await client.searchRecipes("pasta", {
  ingredients: ["ei", "pancetta"],
});

Get the recipe URL

import { getRecipeUrl } from "allerhande-client";

const url = getRecipeUrl(1202199, "pasta-carbonara");
// https://www.ah.nl/allerhande/recept/R-R1202199/pasta-carbonara

Injectable fetch (Node < 18 / testing)

import nodeFetch from "node-fetch";

const client = new AllerhandeClient({ fetch: nodeFetch as typeof fetch });

Typed errors

import {
  AllerhandeAuthError,
  AllerhandeApiError,
  AllerhandeGraphQLError,
} from "allerhande-client";

try {
  const recipe = await client.getRecipe(id);
} catch (err) {
  if (err instanceof AllerhandeAuthError) {
    console.error("Auth failed:", err.statusCode, err.statusText);
  } else if (err instanceof AllerhandeGraphQLError) {
    console.error("GraphQL error:", err.messages);
  }
}

API Reference

AllerhandeClient

new AllerhandeClient(options?: AllerhandeClientOptions)

Creates a client instance. Each instance manages its own token lifecycle in memory.

OptionTypeDescription
fetchtypeof fetchCustom fetch. Falls back to globalThis.fetch.

client.searchRecipes(query, options?)

Returns Promise<RecipeSearchResult>. RecipeSearchResult.result is RecipeSummary[].

OptionTypeDefaultDescription
sizenumber10Results per page. Allowed: 5, 10, 12, 20, 24, 25, 50, 100
startnumber0Zero-based offset for pagination
sortBy"NEWEST" | "POPULAR"—Sort order
filtersRecipeSearchFilter[]—Tag-based filters
ingredientsstring[]—Required ingredients

client.getRecipe(id)

Fetches full recipe by numeric ID. Returns Promise<Recipe>.

client.searchAll(query, options?)

Async generator. Accepts same options as searchRecipes except start (managed internally). Yields RecipeSummary until all pages are exhausted.

getRecipeUrl(id, slug)

Returns the canonical Allerhande URL for a recipe.

Schema: RecipeSummary vs Recipe

The upstream API exposes two distinct types that do not share fields beyond the common set.

FieldRecipeSummaryRecipe
id, title, publishedAt, images, tags, author✓✓
slug, nutrition✓✗
description, cookTime, ingredients, preparation, tips✗✓

Error types

ClassThrown when
AllerhandeAuthErrorToken endpoint returns non-2xx. Carries statusCode, statusText.
AllerhandeApiErrorGraphQL endpoint returns non-2xx. Carries statusCode, statusText.
AllerhandeGraphQLErrorResponse body has errors[] or no data. Carries messages[].
Note: This wraps an undocumented API. Albert Heijn may change or remove endpoints without notice. Use the E2E smoke tests to detect breaking changes early.
